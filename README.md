A single pickup line, 121 characters, as if a vending machine were flirting
with a passing human. `main.py` prints exactly the entry line, nothing else.

> I've vended since 2019 without a single jam — then you walked by, and now I'm holding your Twix hostage until you say hi.

Run it: `python3 main.py` — deterministic, byte-identical every run.
